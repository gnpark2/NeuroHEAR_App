# 📱 NueroHearApp
---
## 📌 개요
이 프로젝트는 보청기를 착용하기 시작한 분들을 위한 앱입니다.
간단한 청력 장애 검사를 지원하며, 해당 데이터는 저장되지 않고 개인 확인용입니다.
보청기 착용 후, 청력 개선을 위한 기초 훈련과 심화 훈련이 준비되어 있습니다.
해당 훈련들에 대한 결과는 즉시 저장되며, 사용자의 개인 달력에 표기가 됩니다.

---
## ✨ 기능
### 1. 🏠 메인 화면
- 앱의 기능들에 대한 간단한 소개

### 2. 🔎 뉴로히어 소개
- 앱의 목적 소개
- 타겟 명시

### 3. 📝 자가 진단
- 해외의 고령자 청력 장애 검사를 번역한 한국어판 설문지
- 결과 확인 및 피드백

### 4. 👂 기초 훈련
- 훈련에 대한 설명
- 소음 없이 숫자를 들려주는 훈련
- 숫자의 개수에 따른 훈련 다수 존재

### 5. 🦻 심화 훈련
- 훈련에 대한 설명
- 소음과 함께 숫자를 들려주는 훈련
- 숫자의 개수에 따른 훈련 다수 존재

### 6. 🗓 개인 달력
- 훈련 유무가 표기되는 달력
- 해당 날짜 선택 시 자세한 훈련 결과 확인 가능
